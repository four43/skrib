WebAuthn PRF Debugger

Test PRF extension support for your browser + authenticator combo

1. Environment

2. Create a test credential (with PRF)

Creates a throwaway credential to test PRF. Uses prf-debug.localhost as RP ID so it won't interfere with your real passkeys.

3. Authenticate & evaluate PRF

Uses the credential from step 2 to request prf.eval and checks if a result is returned.

4. PRF Key Derivation Test

If PRF eval succeeded, derives an AES-256-GCM wrapping key via HKDF and tests encrypt/decrypt round-trip.
